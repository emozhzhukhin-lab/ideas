# Правила для агентов в Ideas

## Область проекта

- Ideas предназначен для личных проектов Евгения. Используй рабочий контекст, только если Евгений прямо попросил связать его с задачей.
- Указывай, какие решения уже приняты, а какие пока предлагаются. Если данных не хватает, обозначай допущение и его влияние на результат.

## Работа с кодом и документами

- Для каждого нового проекта с кодом создавай отдельный локальный Git-репозиторий. Если репозиторий уже есть, работай в нём.
- Держи README проекта актуальным. Укажи назначение, требования и команды запуска и проверки, когда появится рабочий код.
- Соблюдай принятые в репозитории соглашения, сохраняй пользовательские изменения и проверяй результат по обычному сценарию использования.
- Храни пароли, токены, ключи и персональные данные вне Git. Для конфигурации, которую нужно описать, используй примеры без реальных значений.

## Публикация и отчёт

- По умолчанию подготовь локальный репозиторий к публикации. Создавай репозиторий на GitHub и отправляй изменения туда, когда Евгений прямо просит об этом.
- По завершении перечисли изменения, выполненные проверки и всё, что осталось проверить. Укажи ссылку на репозиторий или коммит, если изменения опубликованы.
